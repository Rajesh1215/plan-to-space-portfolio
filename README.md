# Plan / Space

Personal residential-visualisation portfolio by Rajesh, Bengaluru. Plain HTML, CSS and JavaScript, published using GitHub Pages. No build dependencies, tracking scripts, authentication or private credentials.

## Local preview

Run `python3 -m http.server 8085 --bind 127.0.0.1` in this directory.

## Enquiries

The project enquiry button links to a Google Form. Its public responder URL is configured in `app.js`. No enquiry data is collected or stored by this repository. Google Forms owns submission handling and account-configured notifications. Never commit an inbox credential or a form-editor link.

## Content

This is a concept demonstration, not a completed client project. The furnished Blender model was interpreted from a reference layout, with illustrative finishes, terrace and landscape additions. Dimensions are approximate model reference spans, not surveyed clear internal dimensions or construction documentation. The original third-party plan image is intentionally not redistributed here. Images are project renders, not stock photographs. The 67-second video includes exterior and interior sequences, with cuts between room shots.

## Hosting

GitHub Pages: deploy the `main` branch, repository root. Relative asset URLs support project-subpath hosting. This is a portfolio showcase, not an e-commerce or payment application.

## Checks

Verify image enlargement/keyboard closing, the two plan-view buttons, mobile layout, video controls and the Google Form link before sharing. Check the form with a signed-out browser and keep response summaries private.
